# Latium AI Backend

Backend REST API assíncrona para o tutor inteligente de Latim Latium AI.

## Tecnologias
- FastAPI + Uvicorn
- SQLAlchemy 2.0 (Async) + PostgreSQL (pgvector)
- Redis para cache de sessão e memória operacional
- Pydantic v2 para schemas e validação estrita
- Alembic para migrações de banco
- Pytest para testes assíncronos
- Ruff e Mypy para qualidade e tipagem estática
